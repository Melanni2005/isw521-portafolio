# Clase 01 — Arquitectura Web, DNS y URLs

## URL analizada

https://campus.utn.ac.cr/cursos/isw521-2026ii

## Componentes de la URL

| Componente | Valor | Descripción |
|------------|--------|-------------|
| Protocolo | https | Comunicación segura |
| Subdominio | campus | Subsitio dentro del dominio |
| Dominio | utn | Nombre principal |
| TLD | ac.cr | Dominio académico de Costa Rica |
| Ruta | /cursos/isw521-2026ii | Recurso específico |

## ¿Qué es HTTPS?

HTTPS es una versión segura de HTTP que utiliza cifrado SSL/TLS para proteger la información.

## Diferencia entre HTTP y HTTPS

| HTTP | HTTPS |
|------|-------|
| No es seguro | Sí es seguro |
| No cifra datos | Cifra datos |
| Usa puerto 80 | Usa puerto 443 |
| Vulnerable | Más protegido |
